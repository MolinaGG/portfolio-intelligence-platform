# Contribuindo com a Evidaris

1. Nunca use dados financeiros reais em commits, testes, issues ou screenshots.
2. Crie uma branch curta a partir da `main` atualizada.
3. Faça mudanças pequenas e rastreáveis.
4. Atualize documentação e testes quando alterar comportamento.
5. Execute `npm run lint`, `npm test` e `npm run security:audit`.
6. Não desative validações financeiras para fazer um arquivo passar.
7. Abra pull request descrevendo problema, solução, risco, teste e rollback.

Mudanças em autenticação, autorização, migrations, importadores, cálculos, retenção ou documentos jurídicos exigem revisão de outro responsável.
